# UI 全面改版设计文档

**日期：** 2026-03-16
**分支：** ui_change_1
**参考设计稿：** `pencil/account_book_new.pen`

---

## 目标

将微信小程序记账本的所有页面，按照 `account_book_new.pen` 中的 UI 设计进行全面更新，统一视觉风格为橙色主题。保留定期账单提醒功能的全部逻辑，仅更新其 UI 样式。

---

## 实施方案

**方案：全局 CSS 变量驱动 + 共享组件重写 + 逐页结构更新**

1. 先更新 `app.wxss` 全局 CSS 变量（橙色主题）
2. 重写共享组件（bottom-nav、summary-card、record-item、navigation-bar）
3. 按页面逐个更新结构：Tab 主页 → 功能子页 → 设置类子页

---

## 共享组件规范

### bottom-nav

- 5 个 Tab：首页 | 预算 | ➕ | 统计 | 我的
- 中央加号：56rpx 橙色圆形按钮，向上凸出导航栏
- 激活色：`#FF7D00`；未激活：`#999999`
- 高度：100rpx + `env(safe-area-inset-bottom)`
- 背景：白色，顶部 `1rpx solid #EFEFEF` 分割线

### summary-card（首页余额卡片）

- 背景：橙色渐变（`#FF9500` → `#FF7D00`），圆角 24rpx
- 顶部行：标签"本月余额"（白色半透明） + 右侧剩余天数提示
- 中央：余额金额大字（白色，56rpx，700 weight）
- 底部两列：
  - 左：↑ 收入，白色半透明背景圆角块，金额白色
  - 右：↓ 支出，白色半透明背景圆角块，金额白色

### navigation-bar

- 背景：白色
- 左侧：返回箭头（子页面），首页页面无返回
- 中央：页面标题（36rpx，600 weight）
- 右侧：可选操作按钮（如搜索图标、设置图标）
- 底部：`1rpx solid #EFEFEF` 阴影分割

### record-item

- 左侧：80rpx 彩色圆形图标（各分类有固定色），内含图标
- 中间（flex:1）：上行分类名（28rpx，`#1a1a1a`），下行备注+时间（24rpx，`#999`）
- 右侧：金额（32rpx，支出红 `#FA5151`，收入绿 `#4CAF50`）

## 页面结构规范

### 1. 首页 (home)

**布局（从上至下）：**
1. navigation-bar：标题"{{年}}年{{月}}月 ▾" + 右侧搜索/铃铛图标
2. summary-card：橙色渐变余额卡片
3. 快捷操作行：4 个图标按钮（记一笔、语音记账、拍照扫描、预算），横排等宽
4. 待确认草稿提示卡（有待确认记录时显示，橙色边框）
5. 搜索展开面板（searchVisible 时替换 2-4 区域）
6. 最近交易标题行 + "查看全部"链接
7. 按日分组的交易记录列表（swipe-cell + record-item）
8. 本月消费分析：按分类的横向进度条列表
9. bottom-nav（fixed）

**保留功能：** 搜索（关键词/类型/金额/日期）、待确认草稿提示、下拉刷新

### 2. 快速记账 (quick-add)

**布局：**
1. navigation-bar：标题"记一笔" + 右侧"保存"文字按钮（橙色）
2. 支出/收入 Tab 切换（圆角胶囊型，激活态橙色背景白字）
3. 货币符号 + 金额大字输入框（居中，56rpx）
4. 分类网格：4列，图标+标签，激活态橙色圆圈
5. 日期行：日历图标 + 日期（picker）
6. 备注行：备注图标 + 输入框
7. 橙色"确认保存"按钮（全宽胶囊型，固定底部）

### 3. 预算管理 (budget)

**布局：**
1. navigation-bar：标题"预算管理" + 右侧设置图标
2. 月度预算大卡片：总预算金额/已用/剩余/剩余天数，橙色进度条
3. 分类预算列表标题 + "添加"按钮
4. 每个分类预算项：图标+名称 | 已用/预算金额 | 百分比 + 彩色进度条
5. bottom-nav（fixed）

### 4. 统计分析 (statistics)

**布局：**
1. navigation-bar：标题"统计分析" + 月份选择器
2. 收入/支出双卡片（横排，绿色/橙红色背景）
3. 支出趋势标题 + 周/月/年切换 Tab
4. 柱状图（bar-chart 组件）
5. 支出分类标题
6. 饼图（pie-chart 组件）+ 右侧分类占比列表
7. bottom-nav（fixed）

### 5. 交易记录 (records)

**布局：**
1. navigation-bar：标题"交易记录" + 右侧筛选图标
2. 搜索输入框（圆角，灰色背景）
3. 筛选 Tab：全部 | 支出 | 收入 | 本日 | 本月（橙色下划线激活）
4. 按日分组列表：日期标题行（日期 + 当日收支净额），record-item 列表
5. 空状态提示

### 6. 分类管理 (category-manage)

**布局：**
1. navigation-bar：标题"分类管理" + 返回
2. 支出/收入 Tab 切换（橙色激活）
3. 分类图标网格（4列，图标+标签，长按可排序/删除）
4. 底部"+ 添加自定义分类"按钮（虚线边框卡片样式）

### 7. 我的 (settings)

**布局：**
1. navigation-bar：标题"我的"
2. 顶部统计数字横排（本月记账笔数、连续记账天、总记账笔数、已记账天）
3. 数据管理组：数据备份、数据恢复、导出数据、**定期账单**、分类管理
4. 个性化组：主题设置、提醒设置、货币设置
5. 关于/反馈菜单
6. 退出登录按钮（红色文字）
7. bottom-nav（fixed）

### 8. 语音记账 (voice-input)

**布局：**
1. navigation-bar：标题"语音记账" + 返回
2. 提示文字"请说出您的消费记录"（居中，大字）
3. 副提示"点击麦克风按钮开始语音输入"
4. 中央：橙色渐变大圆形麦克风按钮（160rpx）
5. 音波动画条（录音中显示）
6. 示例提示词（橙色浅背景圆角标签）

### 9. 小票扫描 (photo-scan)

**布局：**
1. navigation-bar：标题"小票扫描" + 返回
2. 深色取景框区域（四角橙色边角装饰）+ 相机图标 + 提示文字
3. 橙色"拍照扫描"按钮（全宽，扫描图标）
4. "从相册选择图片"次要按钮
5. 最近扫描标题 + "查看全部"链接
6. 最近扫描列表（日期 + 金额，箭头跳转）
7. 底部扫描小贴士（橙色图标 + 文字）

### 10. 功能子页（统一设计语言）

**定期账单 (recurring)：**
- navigation-bar + 列表卡片（卡片样式更新为圆角白底）+ 右上角"+"按钮
- 保留全部功能逻辑

**定期账单表单 (recurring-form)：**
- navigation-bar + 表单字段（圆角输入框，橙色标记必填）
- 保留全部字段和逻辑

**待确认草稿 (pending-drafts)：**
- navigation-bar + 卡片列表 + 确认/忽略操作按钮（橙色/灰色）
- 保留全部功能逻辑

**预算设置 (budget-setting)：**
- navigation-bar + 金额输入 + 保存按钮（橙色）

**货币设置 (currency-setting)：**
- navigation-bar + 货币选项列表（选中态橙色勾）

**分类表单 (category-form)：**
- navigation-bar + 图标选择网格 + 名称输入 + 保存按钮（橙色）
